三步开始使用

ZnKeyboard 使用你自己的 AI Key。推荐 Google Gemini：有免费额度，一分钟就能申请好。

安装

在上方下载对应版本。Android 安装后还要在系统里启用 ZnKeyboard 输入法，App 首页会引导你完成。

获取 Gemini API Key

登录 Google AI Studio，点「Create API key」创建一个 Key，然后复制。

粘贴，开始用

在 设置 → AI 与语音 里粘贴 Key。看到 API Key 可用 就会自动开启 AI 润色与翻译。

安装帮助

Android：提示「禁止安装未知应用」
  1. 打开下载好的 APK，系统提示时点 设置，允许浏览器或文件管理器安装应用。
  2. 返回后点 安装。
  3. 打开 ZnKeyboard，按首页提示启用输入法。
以后更新：直接安装新版 APK 覆盖即可，设置和 API Key 都会保留。
Mac：提示「未打开 ZnKeyboard」「Apple 无法验证」
  1. 把 ZnKeyboard 拖进「应用程序」后打开。如果被拦截，先点 完成。
  2. 打开 系统设置 → 隐私与安全性，滚到最下面，在 ZnKeyboard 旁点 仍要打开，输入密码确认。
  3. 按提示在 隐私与安全性 → 辅助功能 里打开 ZnKeyboard，它才能读取你选中的文字。
会用终端的话也可以执行：xattr -dr com.apple.quarantine /Applications/ZnKeyboard.app
Windows：提示「Windows 已保护你的电脑」或打不开
  1. 先安装 .NET 10 桌面运行时（x64）。
  2. 把压缩包解压到一个固定的文件夹（比如「文档」），运行 ZnKeyboard.exe。
  3. 如果出现蓝色的 SmartScreen 提示，点 更多信息 → 仍要运行。
  4. ZnKeyboard 会出现在右下角托盘里，右键可打开设置，还可以设为开机启动。

常见问题

要花钱吗？
软件本身免费。AI 请求由服务商按你自己的 Key 计费。Google Gemini 的免费额度足够日常润色和翻译使用，ZnKeyboard 默认用的也是价格最低的 Flash-Lite 模型。
我的文字会发到哪里？
只有在你点「润色」「翻译」或使用 AI 语音输入时，那一段文字才会直接发给你选择的 AI 服务商。ZnKeyboard 没有自己的服务器，不需要注册，也不收集统计数据。API Key 只保存在你的设备上（Android 密钥库、macOS 钥匙串、Windows 凭据管理器）。平时普通打字的内容不会离开键盘。
除了 Gemini 还能用别的吗？
可以用 DeepSeek。在服务商里选择「DeepSeek」，粘贴在 DeepSeek 开放平台申请的 Key 即可。国内可直连，固定使用 deepseek-flash 模型。AI 语音输入仍需要 Gemini Key。
有 iPhone 版吗？
暂时没有。iOS 对第三方输入法限制较多（比如无法可靠地读取和替换已经输入的文字），做出来体验会打折扣。电脑上可以使用 Mac 和 Windows 版。
是开源的吗？
是的。Android 输入法基于 zainbits/zn-keyboard（GPL-3.0）修改，拼音词库来自 雾凇拼音 rime-ice。全部源代码都在 GitHub 上。

三步开始使用

ZnKeyboard 使用你自己的 AI Key，可以选 Gemini 或 DeepSeek：在国内推荐 DeepSeek，在海外推荐 Gemini。

安装

在上方下载对应版本。iPhone 要先安装 TestFlight，并用 Safari 打开安装链接（不要在微信里打开），之后在系统设置里添加键盘并打开完全访问，App 首页会引导你完成。Android 安装后还要在系统里启用 ZnKeyboard 输入法，App 首页会引导你完成；Mac 需要按提示在「辅助功能」里授权，才能读取你选中的文字（截图翻译还需要「屏幕录制」权限）；Windows 双击安装程序即可，第一次需先安装 .NET 10 运行时。

获取 API Key

  • DeepSeek（国内可直连）：登录 DeepSeek 开放平台 创建 Key。按用量付费，需要先充值，翻译一次只要几厘钱。
  • Gemini（有免费额度）：登录 Google AI Studio 创建 Key。需要能访问 Google 的网络。

第一次申请？看详细步骤

粘贴，开始用

打开设置（Android 在底部的「AI」页，iPhone 在 App「翻译」页的「API 配置」，Mac 和 Windows 在菜单栏或托盘图标的「设置」里）：

  • DeepSeek：服务商选「DeepSeek」，粘贴 Key。
  • Gemini：服务商选「Google」（Windows 版写作「Google Gemini」），粘贴 Key。

看到 API Key 可用 就可以用了。

AI 语音输入（Android）需要 Gemini Key，填好后工具栏会出现麦克风。

第一次申请 API Key？

DeepSeek：国内用户推荐
  1. 打开 DeepSeek 开放平台，注册并登录。
  2. 在平台里找到充值入口，建议先充 10 元试用。费用按实际用量从余额扣除，用完再充。
  3. 打开 API Keys 页面，创建一个 Key，马上复制并保存好。
  4. 打开 ZnKeyboard 设置：服务商选「DeepSeek」，粘贴 Key。

DeepSeek 按用量付费，第一次使用前需要先充值。

Gemini：有免费额度，需要能访问 Google
  1. 准备一个 Google 账号，并确认网络能打开 Google。
  2. 打开 Google AI Studio，创建 API Key 并复制。
  3. 打开 ZnKeyboard 设置：服务商选「Google Gemini」，粘贴 Key。

中国内地网络通常无法直接使用 Gemini，国内用户建议选 DeepSeek。

免费额度下，Google 可能用你发送的内容改进产品，也可能由人工查看。请不要发送客户资料、报价等敏感内容。

API Key 相当于账号密码，不要发到群里。团队使用时建议每人一个 Key，方便看用量，泄露时也好更换。

帮助与常见问题

安装遇到问题，或者想了解更多，都可以先看这里。

安装帮助

Android：提示「禁止安装未知应用」
  1. 打开下载好的 APK，系统提示时点 设置，允许浏览器或文件管理器安装应用。
  2. 返回后点 安装。
  3. 打开 ZnKeyboard，按首页提示启用输入法。
以后更新：直接安装新版 APK 覆盖即可，设置和 API Key 都会保留。更新后如果键盘被换成了别的输入法，打开 ZnKeyboard，按首页提示重新选择即可。
iPhone：安装和启用键盘
  1. 在 App Store 安装 TestFlight，并打开一次。
  2. 用 Safari 打开安装链接。在微信里打开时按钮可能没有反应，请选「在 Safari 中打开」。
  3. 在 TestFlight 里点 接受，再点 安装。
  4. 打开「设置 → 通用 → 键盘 → 键盘 → 添加新键盘」，选择 ZnKeyboard，再点进去打开 允许完全访问。翻译需要它，只打字不需要。
  5. 打开 ZnKeyboard App，选择服务商，粘贴 API Key 并测试连接。
以后更新：在 TestFlight 里更新 ZnKeyboard。想用九宫格：在 App「键盘」页的「中文键盘」里选择。
Mac：第一次打开和授权
  1. 把 ZnKeyboard 拖进「应用程序」后打开。
  2. 按提示在 系统设置 → 隐私与安全性 → 辅助功能 里打开 ZnKeyboard，它才能读取你选中的文字。
  3. 第一次使用截图翻译时，再在 屏幕录制 里打开 ZnKeyboard，然后退出并重新打开 ZnKeyboard。
以后升级：有新版本时菜单栏会提醒，点「立即更新」即可（0.3 起），设置、API Key 和权限都会保留，不用重新授权。
Windows：提示「Windows 已保护你的电脑」或打不开
  1. 先在微软下载页安装 .NET 10 Desktop Runtime，选 x64 版本。
  2. 双击下载的 ZnKeyboard-Windows-….exe，会自动安装到本机（不需要管理员权限）并添加到开始菜单，之后下载的文件可以删除。以后有新版本时托盘会提醒，点一下即可更新（0.6 起）。
  3. 如果出现蓝色的 SmartScreen 提示，点 更多信息 → 仍要运行。
  4. ZnKeyboard 会出现在右下角托盘里，并且开机自动启动。单击打开设置，右键打开菜单。卸载：Windows「设置」→「应用」→「已安装的应用」。
遇到问题：右键托盘图标 → 打开诊断日志，连同问题描述一起反馈给我们。日志里不包含任何你输入或选中的文字。

常见问题

要花钱吗？
软件本身免费。AI 请求由服务商按你自己的 Key 计费：DeepSeek 按用量付费，需要先充值，翻译一次只要几厘钱；Google Gemini 的免费额度足够日常使用，ZnKeyboard 默认用的也是它价格最低的 Flash-Lite 模型。
我的文字会发到哪里？
只有在你点「翻译」（Windows 版还有「润色」）或使用 AI 语音输入时，那一段文字才会直接发给你选择的 AI 服务商。ZnKeyboard 没有中转服务器，也不需要注册。应用每天发送一次匿名统计，用于本站的用户数：只有随机编号、平台、版本和使用次数，不含任何文字，可在设置里关闭（Android 在「关于与更新」，Mac 和 Windows 在「通用」）；iPhone 版不发送统计。截图翻译时，截图只在你的电脑上识别，不会上传，只有识别出的文字会发给服务商。API Key 只保存在你的设备上（Android 密钥库、iOS 和 macOS 钥匙串、Windows 凭据管理器）。平时普通打字的内容不会离开键盘，AI 整句排序也在手机上完成。
划词翻译怎么打开？
Mac 版默认已打开：看网页、文档时选中文字，点「翻译为」就行；也可以按 ⇧⌘E，输入框里的文字会直接翻译替换，网页和文档里的文字则弹出译文。不想要小胶囊，可在 设置 →「使用」里关掉 网页和文档。Windows 版要在同一处打开，或者选中后按 Ctrl+Shift+1。翻译成的语言在「划词和截图翻译成」里设置，和截图翻译共用。
快捷键可以改吗？
可以，在 设置 →「快捷键」里点一下快捷键，再按新的组合键即可。Mac 上只有两个：⇧⌘E AI 翻译（输入框里直接替换，网页和文档里弹出译文）、⇧⌘2 截图翻译。Windows 上默认是 Ctrl+Shift+1 划词翻译、Ctrl+Shift+2 截图翻译、Ctrl+Shift+E 润色、Ctrl+Shift+R AI 翻译。
AI 整句排序是什么？
Android 和 iPhone 上，手机里的一个小型语言模型会给键盘猜出的几种整句重新排序，把最通顺的放在第一位，长句、简拼和手误更容易一次打对。它不需要 API Key，也不联网，默认开启；可在 设置 →「键盘」里关闭（Android 在「中文拼音」，iPhone 在「输入」），那里也会显示每次按键花了多少毫秒。
官网和 GitHub 的安装包有什么区别？
安装包完全一样。网站优先从 Cloudflare 下载，国内更快；下载不了时，可以用下载卡片下方的 GitHub 备用链接。App 内更新也是同样的顺序。
可以用哪些 AI 服务？
DeepSeek 和 Google Gemini 都已内置，设置方法见上方三步开始使用。「OpenAI 兼容」（iPhone 版叫「自定义」）还可以接 OpenAI、OpenRouter 等其他兼容服务，填写对方的地址和模型即可。AI 语音输入需要 Gemini Key。
有 iPhone 版吗？
有，目前是测试版，通过苹果的 TestFlight 安装。先在 App Store 安装 TestFlight，再用 Safari 打开安装链接；在微信里打开时按钮可能没有反应。翻译需要你自己的 API Key，并打开完全访问；AI 整句排序不需要。iPhone 版没有语音输入和截图翻译。
是开源的吗？
是的。Android 输入法基于 zainbits/zn-keyboard（GPL-3.0）修改，拼音词库来自 雾凇拼音 rime-ice。全部源代码都在 GitHub 上。
